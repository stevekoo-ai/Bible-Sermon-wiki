# 🎙️ Steve 스타일 가이드 — 어린이 설교 · QT · 나눔

> 새 세션이 Steve의 설교·QT·나눔을 쓰거나 다듬기 전에 읽는 문서.
> 묵상·나눔 **문체 규칙**은 CLAUDE.md §4.1이 단일 출처다. 이 문서는 그 규칙의 **근거와 설교 쪽 패턴**을 정리한다.
> 근거는 Steve가 직접 쓴 원문(Raw Scripts, 나눔 원문, QT 원문)만 썼다. Claude 초안은 근거로 쓰지 않았다.

---

## 1. 어린이 설교 — 뼈대

Steve의 실제 설교는 "대지 1·2·3"으로 나뉘기보다 **질문을 따라가는 수사(搜査)**에 가깝다.
답을 하나 찾으면 "근데.." 하고 다음 질문이 열리고, 그렇게 한 층씩 깊어진다.

| 단계 | Steve의 실제 모습 | 원문 예 |
|---|---|---|
| 시작 인사 | 고정 문구 | "할렐루야 친구들!! ^^", "할렐루야 어린이 친구들!!" |
| 제목 | **도발적인 질문형**이 많다 | "하나님! 왜 약속을 안 지키세요?!", "하나님을 어디서 만날 수 있나요", "사랑이 식으면 죄인가요?" |
| 손들기 | "나는 ~한다 손!!" → 아이 이름을 불러 답을 받는다 | "나는 하나님을 사랑한다. 손!!", "오늘 하나님이랑 D+몇 일?!" |
| 지난 설교 회상 | 시리즈 연결 + 셀프 디스 | "기억나는 사람? 없지? 그럴 줄 알았어!!", 지난 설교 퀴즈 → 선물 |
| 본문 읽기 | "짧으니까 우리 큰소리로 다 같이 읽어보자~ 시작!" | |
| **읽는 도구 가르치기** | 본문 속 **열쇠 단어**를 찾게 한다 — Steve 설교의 가장 큰 특징 | "그러므로가 있으면 꼭 앞에 내용을 확인해야해", "그러나!"(반전), He/You, "7을 만나면 '완전한'으로 바꿔 읽으면 돼" |
| 틀린 추측 먼저 | 일부러 엉뚱한 답을 먼저 던지고 아이들이 웃으며 거르게 한다 | "Ant-man이라도 되어야 하나님 나라에 갈 수 있나?", "이것도 좀 애바야..." |
| **찜찜함 세우기** | 답을 찾은 뒤 정직한 반론을 스스로 꺼낸다 | "뭔가 좀 찜찜하지 않아?", "하나님을 사기꾼 정도로 보지 않으려면", "아직 풀리지 않은 질문이 있을 것 같아.." |
| 깊이 들어가기 | "이제부터 목자님과 같이 더 깊이 말씀을 파고 들어가보자", "목자님을 믿고 다음장으로 넘어가 보자!!" | |
| **하나님의 1인칭 독백** | 절정에서 하나님의 마음을 1인칭으로 풀어 말한다 — "스티브의 메세지 성경" | "내 아들아/딸아… 미안해.. 누구나 그 골짜기를 지나가야 한단다… 그 골짜기에는 내가 기다리고 있어", 십계명 성혼선언문 "사랑하는 신부야!" |
| 정리 | "자 이제 정리해보자", 한 문장 결론, 손가락 셈 | "He는 아.. 아직 못 만났구나 / You & I는 아하 만났구나!" |
| 적용 | 할 일 1~2개 + "하나님 안에 있는 사람은 안전하다" | "1) 부르신 곳에 나를 가져다 놓는 것, 2) 실패하더라도 다시 일어나는 것" |
| 부록 | 시간·분위기를 보고 할지 말지 정함 | "떠들고 안 들으면 여기는 안하려고 했는데, 너희들 너무 잘 따라와 줘서.." |
| 기도 → 주기도문 | 2·3절 아래 참고 | |

## 2. 어린이 설교 — 말투와 재료

**말투**
- 반말, 목자 자칭 "목자님". 질문을 아주 자주 던지고 "그지?", "알겠지?", "기억할 수 있겠어?"로 확인한다.
- 감탄과 유행어: "대박", "빼박", "애바", "완전", "ㅋ", "ㅎ".
- 셀프 유머: 금 변기·금 김밥 "안틸라" FLEX 자랑(2024-11) → 다음 해 설교에서 "리얼리" 친구로 다시 써먹는다(2025-07). **유머를 설교끼리 이어 쓴다.**
- 아이들 실명을 예화 속 등장인물로 넣는다(언니 옷 찢은 이야기 등). *공개 저장소이므로 위키 문서에는 실명을 적지 않는다.*

**재료**
- **어른 수준의 교리를 이름까지 가르친다:** "어려운 말로 '칭의'라고 해", 성화, 영화, 횃불언약(무조건) vs 시내산 언약(조건), 결혼언약으로서의 십계명.
- **숫자와 연대·지도:** BC 959 → 586, "2984년, 16년만 있으면 3천년", 200만 명 × 3끼 × 30일 = "1억 8천인분", 교회에서 비행기 타고 에베소까지 날아가는 지도.
- **역사 증거 자료:** 레크미레 무덤 벽화, 진흙판 등 "진짜 그랬는지 한번 보자!"
- **모형 시연:** 본당 = 무조건 언약, 기둥 = 조건 언약 → "그럼 이제부터 죄를 좀 지어 볼까?" 하며 기둥을 빼는 시연. (손으로 만든 소품은 PPT에 없을 수 있다 — 메모리 "PPT absence ≠ not used")
- **영상 + 확인 퀴즈:** 딕&릭 호잇, 다리 아버지 → "영상 잘 봤지요? 자 질문을 해봅시다!"
- **아이들의 일상:** 컴포즈커피/투썸, 교촌 허니콤보, 케데헌, 아이패드, 인스타 프사, 앞머리 1cm, 핑크색 옷, 시험 망치고 집에 가는 마음, "AI를 시켜서 조사했어 ㅎ".
- **보상:** "찾는 사람~ 사탕!", "맞추는 사람들에게는 선물!"

## 3. 설교 기도문

- 시작: "하나님 감사합니다. 오늘 ~를 통해 ~를 알게 되었습니다."
- 설교의 요점을 **번호로 되짚기도** 한다(2025-07-25: 1.~5.).
- 어른 기도 수준의 고백: "아직은 원하시는 순종의 모습도… 실력도 없는 저입니다… 또 넘어지고, 무너집니다".
- "~줄로 믿습니다", "~하게 하소서!", 반어 선언("살인이라니요!! 생명을 살리는 사람 되게 하실 줄로 믿습니다").
- 고정 마무리: "하나님 지금 하나님께 손 모으고, 고개 숙인 어린이 지구 아이들의 마음과 생각을 지켜 주셔서, … 모든 영광 하나님께 올려드리며, 예수님의 이름으로 기도 드립니다. 아멘!" → "우리 주기도문으로 이 시간 마무리 하도록 하겠습니다."

## 4. 반복되는 신학 줄기

1. **하나님은 약속을 반드시 지키신다** — 무조건 언약(횃불)이 조건 언약의 실패를 받쳐 준다. 시리즈 「하나님 왜 약속을 안 지키세요」.
2. **고난은 약속이 이루어지는 과정** — "하나님이 약속을 지키시기 위해서 그렇게 하셨습니다"(출 1장), "사망의 음침한 골짜기에서 만나자고 하셨다".
3. **하나님의 열심** — "넘어진 그 자리에 절대 놔두지 않아, 다시 일으키시고".
4. **안전함** — "하나님 안에 있는 사람들은 안전하다", "내가 주님 안에서 가장 안전함을 믿습니다".
5. **선택받은 은혜** — 겨자씨를 채소밭에 심으심, 작은 배 어부가 건져 올린 10명.
6. **관계의 언어** — 하나님은 신랑, 우리는 신부. "사랑은 두 사람의 온도가 같아야 해".

## 5. QT · 묵상 (CLAUDE.md §4.1 근거)

- 머리: 날짜 + 본문만 ("10/30 QT / 시편 18편"). 소제목·번호 없다.
- 첫 줄은 그날의 상황인 경우가 많다 ("오늘은 특별히 금찬 예배에 불러주셔서, 이제 곧 교회도착!! ^^").
- **스스로 묻고 짧게 답한다:** "그럼 돌이킨 경우는 있었나? / 있지. 있지.", "그래 경고다…".
- **상상 장르:** 시드기야가 바벨론 옥에서 받아 적게 한 시편.
- 삶의 무대: 회사(사업부 폐쇄·전배·영어 미팅·평가 면담·"팀장 주인님"), 가족(아내, 남동생 전도, 아이들), 돈(전세·청약·커피 쿠폰).
- 결론은 "섭리" 쪽으로 간다: "나는 그냥 출근했다 퇴근했다 했을 뿐인데, 하나님의 섭리가 일하여…".
- 셀프 유머: "나 하나 연단하느라 엑스트라만 80억이다 ㅋ", "택도 없다.. (요즘 이 표현을 많이 쓰네..)".
- 끝: "모든 영광 하나님께 있습니다!" / "모든 영광 하나님께 올려 드립니다."

## 6. 나눔 (목장)

- 해라체 수필(~다, ~했다). 첫 문장은 고백이나 장면으로 훅 들어간다: "사실.. 나는 사기 결혼을 했다.", "이번주 목요일 HPE와 미팅이 있었다."
- **일상의 물건 하나가 중심 은유:** 전자담배·오렌지 슬러시 얼룩, 연필깎이, 만보기와 "STOP", 감사의 렌즈, "하나님이 쎄? 마늘이 쎄?".
- 아내의 한마디가 전환점이 되곤 한다 ("한번에 다 못 팔겠으면 조금씩 나눠서 해!").
- 끝은 기도 한 줄 + "모든 영광 하나님께 올려 드립니다. 아멘!"
- 편집 규칙: Steve가 완성해 준 글은 오타만 고친다(§4.1). "재구성해 줘"라고 할 때만 흐름을 바꾸고, 원문은 아래에 그대로 둔다.
