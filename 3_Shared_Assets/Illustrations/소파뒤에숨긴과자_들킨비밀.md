# 🍪 예화: 소파 뒤에 숨긴 과자

## 상황 설명
[과자 봉지를 들고] "우리 친구들, 과자 먹고 싶은데 엄마가 '밥 먼저 먹어야지' 하실 것 같으면 어떻게 해요?"
어떤 친구는 몰래 소파 뒤에 과자를 숨겨놓고 "엄마가 못 보실 때 살짝 먹어야지~" 하고 계획을 세워요.
[소파 뒤에 과자를 숨기는 시늉] 그런데... 엄마는 어떻게 아셨을까요? 부스러기가 떨어져 있었거나,
입가에 초콜릿이 묻어있었거나, 아니면 그냥... 처음부터 다 보고 계셨어요!

## 신학적 요점 연결
다윗도 비슷한 계획을 세웠어요. 다윗이 큰 잘못을 했는데, 사람들이 모르게 하려고
몰래 계획을 짰어요 — 전쟁터에 나가있던 우리아 아저씨를 집으로 불러들인 거예요(삼하 11:6-8).
과자를 소파 뒤에 숨기듯이, 다윗도 자기 잘못을 숨기려고 한 거예요.

## 진행 방법 (Kid-Friendly Delivery)
1. 과자를 소파 뒤에 숨기는 상황극을 짧게 보여준다.
2. "이 친구는 왜 몰래 숨겼을까요?"라고 물어본다 — 아이들: "엄마한테 혼날까 봐요!"
3. "맞아요, 몰래 하면 아무도 모를 것 같죠? 그런데 오늘 이야기에서 다윗도 똑같은 마음으로
   몰래 계획을 세웠대요. 어떻게 됐는지 한번 볼까요?"

## 적용 문장 예시
"우리도 가끔 잘못한 걸 숨기고 싶을 때가 있어요. 그런데 숨긴다고 진짜 없어지는 게 아니에요.
오늘 다윗 이야기에서 그걸 배워볼 거예요."
