# 에스라–느헤미야는 한 권의 이야기 + 말라기의 연대

표시: ✅ 직접 확인 / 🔸 2차 자료로 확인 / ❓ 추론·기억

## 1. 말라기는 언제인가
**본문 단서 (Fact ✅)** — 총독(페하, 1:8) → 페르시아 시대 / 제단·성전 운영(1:7, 10) → 515 이후 / 레위 언약 깨뜨림(2:4-8) / 이방 결혼·이혼(2:11-16) / 십일조(3:8-10). 에스라·느헤미야 이름은 없음.

**대응표 (Fact ✅)**
| 말라기 | 에스라·느헤미야 |
|---|---|
| 이방 결혼 2:11 | 스 9:2; 10:3; 느 10:30; 13:23 |
| 십일조·창고 3:8-10 | 느 10:37-38; 13:10, 12 |
| 하나님의 전을 업신여김 1:7, 10 | 느 10:39 "전을 버려 두지 아니하리라"; 13:11 "전이 어찌하여 버린 바 되었느냐" |
| 제사장 타락·레위 언약 2:1-9 | 느 13:4-5 엘리아십의 방; **13:29 "레위 사람에 대한 언약을 어겼사오니"** (같은 표현) |
| 형제 학대 2:10; 3:5 | 느 5:5 |
| 총독 1:8 | 느 5:14 |
→ 가장 많이 겹치는 곳: **느헤미야 13장**.

**학자 견해**
| 견해 | 학자 | 등급·확인 |
|---|---|---|
| (a) 에스라 이전 500–460 | Hill AYB 25D "약 500" / Stuart 약 460 / Merrill 480–470 / R. Smith WBC 5세기 전반 | ★★★ 🔸 |
| (b) 에스라–느헤미야 사이 458–445 | Harrison, Bright 약 450 | ★★★ 🔸 |
| (c) 느헤미야 부재 중 433 무렵 이후 | **Verhoef NICOT "433 직후"** / Freeman / Archer 약 435 | ★★★ 🔸 |
- 근거(c): 느 13:6 "아닥사스다 삼십이년에 내가 왕에게 나아갔다가" ✅
- **연표 권고:** 점이 아니라 **BC 약 470–430 띠**. 어느 견해든 말라기는 에스라·느헤미야 **앞뒤에서 같은 문제를 다룬 선지자**.

## 2. 한 권이었다는 증거
- 마소라 끝 메모: 합본 685절, 가운데 절 **느 3:32** 🔸 — 개역개정 실측 280+406=686절, 느 3:32는 343번째 ✅(계산), 1절 차이는 느 7:68 부재 추정 ❓
- 탈무드 바바 바트라 15a: 에스라가 자기 책을 쓰고 느헤미야가 완성 ✅(Sefaria) ★★
- LXX "에스드라스 B" 한 권 🔸 / 오리겐 "이중의 책", 제롬 에스라 1·2서, 라틴 9–13세기 분리, **히브리어 성경은 1516/17 봄베르크 랍비 성경에서 처음 분리** 🔸

## 3. 구조 — 시간 순서? 두 관점? → "한 권의 신학적 이야기" (학계 주류, Opinion)
- 세 번의 귀환과 회복: ① 스룹바벨·성전(스 1–6) ② 에스라·율법과 공동체(스 7–10, 느 8) ③ 느헤미야·성벽(느 1–7, 11–13). 매번 "하나님이 왕의 마음을 움직이심 → 지도자 파송 → 일 → 큰 모임".
- 절정: 느 8–10(낭독·초막절·회개·언약) → 성벽 봉헌(12:27-43), 두 사람이 행렬 양쪽에(12:36 "학사 에스라가 앞서서", 12:38 느헤미야).
- **Eskenazi, *In an Age of Prose* (1988) ★★★ 🔸**: 세 주제 = 백성(공동체) · 하나님의 집 · 기록된 문서(p.40). 하나님의 집 = 성전 + 성벽 도시 + 백성. 영웅 이야기가 아니라 공동체 이야기.
- Williamson WBC(1985) 3단계 편집 🔸 / Blenkinsopp OTL, Fensham NICOT ❓

## 4. 연대 논쟁
| 견해 | 내용 | 위치 |
|---|---|---|
| 전통 | 아닥사스다 1세: 에스라 458, 느헤미야 445 | 다수 |
| 에스라 후대설(Van Hoonacker 1890) | 아닥사스다 2세: 에스라 398. 근거 스 10:6 여호하난 = 엘레판티네 파피루스의 요하난(410경), 스 9:9 "울타리" | 소수, 논쟁 중 (반론 Cross JBL 1975 ★★★) |
| 428설 | 7년 → 37년으로 수정 | 거의 지지 없음 |
- **느 8장 원위치**: 많은 비평 학자가 에스라 도착 첫해(458) 7월로 봄. 에스드라 1서는 에스라 1–10 뒤에 느 8 낭독(9:37-55)을 붙여 끝남 🔸. 정경은 현재 순서.
- 느 8:9 "총독 느헤미야": 에스드라 1서 9:49에 이름 없음 ✅ → 후대 삽입설(비평) vs 함께 있었다는 증거(전통).

## 5. 서로의 이야기에 나오는 곳 (✅)
- 느 8:1-18 학사/제사장 에스라 / 12:26 "느헤미야와 … 에스라 때" / 12:36 봉헌 행렬 선두
- ⚠️ 느 12:1, 12:13, (12:33)의 에스라는 동명이인

## 6. 느헤미야 정독 핵심 (Claude, DB ✅)
- 1:1-4 아닥사스다 20년(445) 수산 궁 — "성은 허물어지고 성문들은 불탔다" → 울고 금식 기도
- 2:8 "내 하나님의 선한 손이 나를 도우시므로" (스 7:9과 같은 표현)
- 4:6 "백성이 마음 들여 일을 하였음이니라" / 6:15-16 52일 만에 완공, 대적이 "하나님께서 이 역사를 이루신 것을 앎"
- 7:4-5 "주민은 적으며" → "내 하나님이 내 마음을 감동하사" 계보 등록
- 8장 낭독 → 9:1-3 금식·자복, 9:36 "우리가 오늘날 종이 되었는데" → 9:38 언약
- 10:28 "그들의 아내와 그들의 **자녀들** 곧 지식과 총명이 있는 자들" → 10:29 "지켜 행하여" / 10:39 "하나님의 전을 버려 두지 아니하리라"
- 12:43 "**부녀와 어린 아이도** 즐거워하였으므로 … 멀리 들렸느니라"
- 13:6 아닥사스다 32년(433) 귀환 후 다시 옴 → 13:10-11 레위인 도망, 13:15 안식일, 13:24 "유다 방언은 못하니", 13:31 "내 하나님이여 나를 기억하사"

## 7. 종합 (Opinion)
- 따로 시작한 두 이야기(율법 / 성벽)가 수문 앞 광장(느 8)과 봉헌식(느 12:36)에서 만난다. 하나님의 "집"은 돌만이 아니라 **말씀 아래 모인 백성**.
- 스 7:10 "연구·준행·가르침"은 이 책이 공동체에게 바라는 모습을 한 사람 안에 먼저 보여 주는 장면.
- 말라기·느 13: 개혁 뒤에도 다시 무너짐 → 이야기는 열린 채 끝나고, 끝까지 일하시는 하나님을 가리킨다.
