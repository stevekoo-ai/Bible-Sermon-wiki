# 성전 재건을 언급한 예언 전수표

검색어: 성전 · 여호와의 전 · 내 집 · 하나님의 집 · 기초 · 지대 · 건축 · 성소 · 중건 (사–말).
제외: 첫 성전 시절·파괴 본문(렘 7, 26, 52; 겔 8–9; 애 1–2; 미 3:12 등), 창조의 기초, 일반 가옥, 이방 성소.

## 5. [성취 기록]
- 대하 36:22-23; 스 1:1-4 "예레미야의 입을 통하여 하신 말씀을 이루게 하시려고"(538)
- 스 3:6 "성전 지대는 미처 놓지 못한지라" → 3:8-13 기초(536), 찬송과 통곡
- 스 4:24 → 5:1-2 중단, 학개·스가랴로 재개
- 스 6:14-15 "학개와 … 스가랴의 권면을 따랐으므로 … 다리오 왕 제육년 아달월 삼일에"(≈ 515.3.12). 에스라 7장(458)은 약 57년 뒤.

## 6. 하나님이 친히 돌아와 거하신다는 말씀 (시제별)
- 포로기: 겔 10:18; 11:23 떠나심 / **겔 11:16 "내가 잠깐 그들에게 성소가 되리라"**
- 귀환(미래): 사 52:8 "여호와께서 시온으로 돌아오실 때에"; 사 40:9
- 재건 중(현재): 학 1:13; 2:4 "내가 너희와 함께 하노라"; 2:5 "나의 영이 계속하여 너희 가운데에 머물러 있나니"
- 재건 중(완료·미래): **슥 1:16 "돌아왔은즉"(완료형, 미확인)**; 슥 1:3 조건부; 슥 2:10-11 미래; 슥 8:3 논쟁
- 환상: 겔 43:2-7; 48:35
- 완공 후에도 남은 미래: 말 3:1
- Fact: 에스라–느헤미야에 구름·영광이 채웠다는 기록 없음(왕상 8:10-11, 대하 7:1과 대조), 언약궤 없음.
- Opinion: 임재는 있었고 가시적 영광은 유보(학 2:5, 겔 11:16) / 랍비 전통 "둘째 성전에 없던 다섯 가지"(요마 21b, ★★ 미확인) / 신약: 성전에 오신 예수님으로 성취(눅 2; 요 2:19-21).

## 7. 재건된 성전의 이후 운명
- 학 2:9 영광 증대 약속
- 말 1:10; 3:3 예배 타락 → 정화
- 단 8:11-14; 11:31 더럽힘(안티오코스 4세, BC 167 통설; 마카베오상 1:54) → 마 24:15
- 단 9:26-27 "그 성읍과 성소를 무너뜨리려니와"(AD 70 전통 / 안티오코스 비평)
- 슥 11:13(마 27:9-10), 슥 14:21(요 2:16), 사 56:7(막 11:17) — 헤롯 시대 성전 심판·청결

## 신뢰도
- 본문 인용: 개역개정 DB 원문(Fact).
- 날짜 환산: 학계 통상 환산(★★★ 계열) — 주석서로 확인 권장.
- 해석 갈래: 일반 주석 지식, 개별 출처 미확인 → 인용 전 확인.
